## What was built

| Piece                           | What it does                                                                                                      |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `packages/mcp/src/server.ts`    | MCP stdio server: newline-delimited JSON-RPC 2.0, `initialize`, `ping`, `tools/list`, `tools/call`                |
| `packages/mcp/src/tools.ts`     | The five tools, input validation, path confinement to `--root`                                                    |
| `packages/mcp/src/gate.ts`      | `run_gate`: journal setup, `routespec gate run` through the reviewed launcher, one subject process per case       |

| `packages/mcp/src/scenarios.ts` | Reviewed synthetic scenario `slow-deposit-answer` (ADR-0031, decision 5)                                          |

| `packages/mcp/src/knowledge.ts` | `explain_invariant` and `show_fix_pattern`: kernel templates and four SDK fix patterns                            |
| `packages/cli/src/main.ts`      | `routespec mcp` hands stdio to the MCP server                                                                     |
| `examples/agent-skill/SKILL.md` | Plain Markdown skill for coding agents                                                                            |
| `examples/agent-skill/mcp.json` | MCP configuration example                                                                                         |
| `examples/agent-skill/gate.ts`  | Shell fallback for agents without MCP                                                                             |
| `examples/agent-skill/demo/`    | Naive and fixed client, scripted agent session, recorded `TRANSCRIPT.md`                                          |

## README snippet (for the owner; `README.md` is not edited by this module)

```markdown
### For coding agents: skill and MCP server

RouteSpec ships an MCP server and a plain Markdown skill for coding agents. The rule: before
shipping 1Click code, run the gate; on FAIL apply the reconcile pattern.

- Skill: `examples/agent-skill/SKILL.md`. MCP configuration: `examples/agent-skill/mcp.json`
  (`node --no-warnings packages/cli/bin/routespec.mjs mcp --root .`).
- Tools: `run_gate`, `list_findings`, `explain_invariant`, `show_fix_pattern`, `verify_certificate`.
- Demo: `pnpm run demo:agent-session`. A scripted agent runs the real gate on a naive client
  (FAIL, INV-03: a second order while the first is unanswered), applies the reconcile pattern,
  and runs the gate again (PASS). Recording: `examples/agent-skill/demo/TRANSCRIPT.md`.
- MCP gate runs are local, networkless and uncontained: diagnostic, not release evidence.
```
