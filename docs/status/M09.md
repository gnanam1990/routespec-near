## Red / green evidence (honest account)

The shell source was written before most of its tests in this stage. Real red results that changed
product code:

- Layout at 375/768/1024/1440 → exit 1, **4 failed**: body horizontal overflow of 51–491 px. Cause:
  visually-hidden text inside table scrollers escaped clipping. Fixed by positioning `.table-scroll`
  and `.app-main`; rerun 10 passed.
- Keyboard evidence journey → exit 1, **2 failed** (both viewports): the shell moved focus to the
  page title after the drawer route opened, then focus was not restored to the evidence link on close.
  Fixed with a `data-route-focus` target and a `restoreFocus` route state; rerun 8 passed.
- Test-only corrections: an over-broad text assertion (status), CSP correctly blocking an injected
  `<style>` (switched to CSSOM), a pause check counting in-flight bounded retries, a scanner
  false positive on a literal test bearer string.

## Security and privacy review (shell scope)

- Control token: memory only; fragment removed via `history.replaceState`; `credentials: 'omit'`,
  `referrerPolicy: 'no-referrer'`, `redirect: 'error'`; no cookies or storage (guard test).
- One-time case/recovery tokens are rendered once in a labelled panel and dropped from memory on
  acknowledgement; they never enter history, storage, or exports.
- Provider credentials: the console receives only the provider-token state enum.
- No `innerHTML`/`dangerouslySetInnerHTML`; trace content renders as text only.
- The build runs under `default-src 'none'; script-src 'self'; style-src 'self'; font-src 'self';
connect-src 'self'; frame-ancestors 'none'` (verified in e2e: no CSP violations).
- The fixture binds 127.0.0.1, rejects foreign Host headers, and never prints its token.
