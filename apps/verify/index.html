What a certificate proves

It proves

An attester key that the registry owner enrolled, and has not revoked, signed these values: the bundle digest, the gate verdict, the corpus digest, the client artifact digest, the commit and a timestamp. The signature is checked here, so the RPC endpoint cannot invent a certificate.

It does not prove

It does not prove that the gate was run honestly, that the build is the one the commit produces, or that the project blocks releases on it. The RPC endpoint is trusted to report enrolment and revocation; it could hide a certificate. For more assurance, pin the attester key and run routespec certificate verify with the bundle, which also verifies the bundle contents.

The decision on this page is the one routespec certificate verify --digest reaches, computed by the same code. Read-only view calls; no wallet, no transaction.
