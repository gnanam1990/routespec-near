## Real vs simulated vs blocked

- **Real:** every command above on this machine, the container engine, Ed25519 keys generated
  locally for the journeys, real signatures and verification, the read-only `pnpm audit` query.
- **Simulated (by design):** provider behaviour and ground truth (networkless SIMULATE), the CI
  runner environment in the M10 tests, the fixture API of `pnpm run test:e2e` (development only),
  the request delay in the new T-051 test (the response itself comes from the real service).
- **Blocked or NOT_RUN:** remote CI run (owner's action, reported separately), independent profile
  review, independent security review, RP-07, Linux and macOS hosts, Firefox and WebKit, WSL
  `mirrored` mode, plain Linux Docker, rootless engines.
